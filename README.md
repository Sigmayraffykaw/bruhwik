# BruhWik

A premium Spotify customization concept built with Next.js, Tailwind CSS, Framer Motion and Lucide icons.

## Download behavior
The current desktop client is not released. Download buttons generate honest platform-specific setup guides instead of pretending to provide an installer. Replace `downloadGuide()` with official release URLs when signed binaries are ready.

## Run locally
```bash
npm install
npm run dev
```
